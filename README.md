# Временная карта: Амурская область и Приморский край

Обзорные картографические материалы проекта ПодборПродуктАгент. Публичные слои предварительные; T10 и «белые пятна» не являются финально утверждёнными.

Основной терминал проекта не изменяется. Для публикации на Render используется `index.html` в корне репозитория.
